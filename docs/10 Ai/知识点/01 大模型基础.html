1. token是什么？大模型为什么要用token而不是字数

Token 是大模型处理文本时的基本单位，模型会把它转换成数字 ID 和向量进行计算。

大模型不直接使用字数，是因为字符和单词都无法兼顾多语言、未登录词、词表规模与计算效率，而子词级 token 能在表达能力和计算成本之间取得较好的平衡。

Token 是大模型处理文本时的基本单位。它不是严格意义上的“字”或“单词”，而是由分词器切分出来的一段文本，并被映射为一个整数 ID。

例如，一句话可能被切分为：

"我喜欢人工智能"
→ ["我", "喜欢", "人工", "智能"]
→ [Token ID 1, Token ID 2, Token ID 3, Token ID 4]

实际切分结果取决于模型使用的分词器。英文中，一个 token 可能是完整单词、词根、前后缀或标点；中文中，一个 token 可能对应一个汉字、多个汉字，甚至字节片段。

大模型使用 token 而不是字数，主要有以下原因：

  1. 计算机不能直接理解文字 模型需要先把文本转换为数字。分词器把 token 映射为整数 ID，再通过 embedding 转换成向量供神经网络计算。

  2. “字”无法统一描述不同语言 中文以汉字为主，英文以单词为主，其他语言还有不同的书写系统。token 提供了一种相对统一的多语言表示方式。

  3. 按词切分会遇到未登录词 如果只把完整单词作为单位，词表会非常大，而且新词、人名和拼写变化无法覆盖。子词 token 可以把陌生单词拆开，例如：

    unbelievable → un + believe + able

    即使完整单词不在词表中，模型也能处理。

  4. 在词表大小和序列长度之间取得平衡 按字符切分，词表较小，但序列会很长，计算成本高；按完整单词切分，序列较短，但词表过大。子词 token 是两者之间的折中。

  5. 模型的计算量天然按 token 计算 上下文窗口、输入输出限制、推理速度和 API 费用通常都与 token 数有关，而不是字数。
