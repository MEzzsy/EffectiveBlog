# 模型基础

## 大语言模型

大语言模型（LLM）是在大量文本上训练的深度学习模型，能够理解并生成人类语言。

# 输入与输出

## Token

Token 是模型处理文本时使用的基本单位，可以是一个字、一个词或词的一部分。

## 上下文窗口

上下文窗口是模型一次能够读取和处理的 Token 数量上限，包含输入内容和生成内容。

## 提示词

提示词（Prompt）是用户提供给模型的指令、问题和背景信息，用于引导模型生成符合预期的结果。

# 知识增强

## Embedding

Embedding（嵌入）是将文本、图片等内容转换为数值向量，以便计算机比较它们的语义相似度。

## 向量数据库

向量数据库用于存储和检索向量，能够快速找出与查询内容在语义上相近的数据。

## RAG

RAG（检索增强生成）是先从外部知识库检索相关信息，再让模型结合这些信息生成答案的技术。

# 智能体

## 工具调用

工具调用（Tool Calling）是模型按照约定格式请求外部程序执行搜索、计算或文件操作等任务。

## Agent

Agent（智能体）可以理解为一个能够围绕目标自主完成任务的 AI 执行者。

Agent 不等于大语言模型。大语言模型主要负责理解和生成内容，Agent 则以大语言模型作为推理核心，再组合规则、上下文、记忆、工具和执行循环：

```text
Agent
= 大语言模型
+ 身份与行为规则
+ 上下文与记忆
+ 工具与权限
+ Agent Loop
```

## Agent Loop

Agent Loop（智能体循环）是智能体反复进行观察、思考、行动和检查，直到完成目标或满足停止条件的过程。
