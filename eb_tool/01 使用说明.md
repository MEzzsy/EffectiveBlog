# 启动工具

在仓库根目录运行：

```sh
python3 eb_tool/eb_tool.py --ui
```

工具使用 Python 标准库，兼容 Python 3.9 及以上版本，无需安装前端依赖。启动后自动打开浏览器，默认地址为 `http://127.0.0.1:8765`。按终端中的 Ctrl+C 停止服务，正在进行的操作会先完成。

端口被占用或希望自行打开浏览器时：

```sh
python3 eb_tool/eb_tool.py --ui --port 8766 --no-browser
```

也可以使用脚本绝对路径从其他工作目录启动。管理根目录默认是 `eb_tool` 文件夹的上一级；`--root /path/to/repository` 可指定其他管理目录。配置始终读取脚本同级的 `eb_config.json`，不会随工作目录或 `--root` 改变。

# 整理文档

- 界面采用 macOS 风格的深色层级列表。点击目录左侧箭头可在原位置展开或收起子目录与文档，缩进表示层级。
- 点击左侧导航中的目录，或双击列表中的目录进入。底部路径栏和左上角返回按钮用于返回上级目录。
- 搜索框按名称或相对路径搜索整个管理范围。按 `/` 快速聚焦搜索框。
- 单击项目选中，Cmd/Ctrl 单击切换选择，Shift 单击连续选择。输入框外的 Cmd/Ctrl+A 或工具栏“全选”选择当前可见项目；折叠目录时隐藏的选中后代会改为选中该目录。
- 上下方向键选择相邻项目，左右方向键展开、收起或定位父子项目；Shift 配合上下方向键连续选择。
- 选中一个项目，点击“重命名”或按 F2，只需输入标题，按 Enter 保存；Escape 取消。Markdown 的扩展名自动保留，序号自动处理。
- 选中一个或多个项目，拖到左侧目录或列表中目录行的中间即可移入；也可点击“移动到…”选择目标。选择父目录和其后代时，只处理父目录一次。
- 同目录排序：将项目拖到同类项目行的上边缘或下边缘，出现蓝色插入线后松开，分别插入到该项目之前或之后。目录行的中间仍用于移入，目录展开时，下方插入线显示在其整个子树之后。
- 可以多选同目录的文件或目录一起排序，所选项目按原有顺序整体插入。文件和目录分别排序，README 不参与；搜索结果中不提供排序，先进入相应目录再调整。拖拽到列表上下边缘可滚动，按 Escape 取消。
- 点击“新建目录”创建自动编号的目录，并在其中自动创建空的 `README.md`。

文件位置和名称在操作完成后立即生效，文档链接及图片路径自动更新，随后按已有规则重新生成 `SUMMARY.md`。新目录通过自动创建的 README 出现在 SUMMARY 中。已有的无 README 目录仍可在界面中管理，SUMMARY 沿用原有规则。

## 自动编号规则

- 每个目录内，Markdown 文件与子目录分别从 `01` 连续编号，范围为 `01`–`99`，统一采用 `01 标题` 格式；兼容已有的单数字、空格或连字符前缀。
- 新建、重命名、拖拽排序后整理所在目录的两类序号；跨目录移动后同时整理源目录和目标目录，补齐起始编号和中间空号。读取或刷新列表不会改动文件。
- 现有项目按原序号顺序排列，未编号项目排在已编号项目之后；同号或未编号项目按原名称、路径稳定排序。重命名保留项目原有排序位置，输入中自带的编号不用于指定位置。
- 新建、移入项目排在目标目录同类项目末尾。例如目标只有 `07 文档.md`，移入笔记后，原文档改为 `01 文档.md`，笔记成为 `02 笔记.md`；空目录的首个项目为 `01`。
- 拖拽排序将同类项目按新顺序从 `01` 连续编号。例如把 `03 丙.md` 拖到 `01 甲.md` 之前，会得到 `01 丙.md`、`02 甲.md`、`03 乙.md`。
- 同级项目因补齐或调整序号而改名时，其引用、图片路径及 SUMMARY 同步更新；目录自身改名后，后代路径也会同步调整。未直接整理的目录不单独重排其内部项目。
- `README.md` 保留特殊名称，不参与编号。将 README 改为普通文章名称时会自动编号。
- 同标题的普通项目可通过不同编号共存；最终路径同名仍拒绝覆盖。同一目录的同类编号项目超过 99 个时停止整批操作，并提示选择其他目录。

# 撤销与冲突

点击“撤销”或在输入框外按 Cmd/Ctrl+Z，可撤销最近一次成功操作，同时恢复所选项目及自动改号的同级项目的原始位置、编号、被改写的正文和 SUMMARY。新建目录的撤销会一并移除自动创建的空 README；README 被外部编辑后会拒绝撤销。输入框内保留浏览器原生的文字撤销。

撤销记录仅保存在当前服务进程的内存中。后续成功操作替换记录；刷新页面保留记录，停止或重启服务会清除记录，不提供重做。

如果编辑器或其他工具修改了文件，提交操作时可能提示先刷新。撤销前也会检查受影响文件和目录；发生外部修改时会拒绝撤销，避免覆盖修改。与操作无关的外部编辑不会阻止刷新后的撤销。

目标同名、目录移入自身或后代、路径越界、符号链接和特殊文件都会被拒绝；不会覆盖文件或合并目录。执行失败时尝试恢复整次操作。若提示某些项目未能恢复，应根据错误中列出的路径检查现场，工具不会将部分成功当成成功。

# 管理范围与代码职责

界面只显示可管理目录和 Markdown 的名称、路径，不提供正文预览、编辑、新建 Markdown、删除或批量重命名。

根 README、SUMMARY、AGENTS、工具目录、构建产物和依赖不作为整理对象。子目录 README 可整理，保留 README 名称时不编号。资源目录不作为单独的整理对象，移动其父目录时连同资源与隐藏文件一起移动。

`eb_tool.py` 负责所有运行时文件访问、HTTP 接口、重命名、移动、排序、新建目录、引用更新、SUMMARY 生成、回滚及撤销；`ui/` 只负责界面与 API 请求。新增文件操作功能也应补充到 `eb_tool.py`。

排序接口为 `POST /api/reorder`，传入 `paths`（所选项目的相对路径数组）、`anchor`（参照项目的相对路径）、`position`（`before` 或 `after`）和最新的 `revision`。它与其他写接口共用会话校验、整批预检、失败回滚及最近一次撤销。

本地服务仅监听 `127.0.0.1`，不提供远程访问。API 使用会话令牌和来源校验，前端只向同一服务发送请求；静态文件接口不会公开文章正文或工具配置。

# 命令行兼容

原有命令保留，脚本路径改为 `eb_tool/eb_tool.py`：

```sh
python3 eb_tool/eb_tool.py --gen
python3 eb_tool/eb_tool.py --clean_img --dry-run
python3 eb_tool/eb_tool.py --clean_img --delete
python3 eb_tool/eb_tool.py --format_img
python3 eb_tool/eb_tool.py --move_md "旧目录/01 文档.md" "新目录"
python3 eb_tool/eb_tool.py --move_md "目录/01 旧名称.md" "目录/01 新名称.md"
```

`--move_md` 与 UI 共用从 01 连续编号和引用更新逻辑，指定文件移出后其同级项目也会补齐编号；保留单文件操作入口，不额外重新生成 SUMMARY。UI 额外提供批量移动、整目录操作、自动重新生成 SUMMARY 和会话内撤销。

# 验证

在仓库根目录执行：

```sh
python3 -B -m unittest discover -s eb_tool/tests -v
node --test eb_tool/tests/test_ui.js
```

Python 测试使用标准库及临时仓库，HTTP 测试会在本机临时端口启动服务。Node.js 仅用于运行前端逻辑测试，正常使用工具不需要 Node.js。
