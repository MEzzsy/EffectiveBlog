# 什么是人工智能

人工智能（AI）是让计算机模拟人类感知、理解、推理、学习和决策能力的技术统称。

# 什么是机器学习

机器学习（ML）是让计算机从数据中学习规律，并利用这些规律进行预测或决策的方法。

# 什么是深度学习

深度学习（DL）是机器学习的一个分支，使用多层神经网络从大量数据中自动提取特征。

# 什么是神经网络

神经网络是一种受人脑神经元连接方式启发的计算模型，由多层节点组成，用于学习数据中的复杂关系。

# 什么是生成式 AI

生成式 AI 是能够根据已有数据生成文本、图片、音频、视频或代码等新内容的人工智能。

# 什么是大语言模型

大语言模型（LLM）是在大量文本上训练的深度学习模型，能够理解并生成人类语言。

# 什么是参数

参数是模型在训练过程中学习到的数值，决定了模型如何处理输入并生成输出。

# 什么是 Token

Token 是模型处理文本时使用的基本单位，可以是一个字、一个词或词的一部分。

# 什么是上下文窗口

上下文窗口是模型一次能够读取和处理的 Token 数量上限，包含输入内容和生成内容。

# 什么是提示词

提示词（Prompt）是用户提供给模型的指令、问题和背景信息，用于引导模型生成符合预期的结果。

# 什么是训练

训练（Training）是让模型通过大量数据不断调整参数、学习规律的过程。

# 什么是推理

推理（Inference）是训练完成的模型根据新输入生成答案或预测结果的过程。

# 什么是微调

微调（Fine-tuning）是在预训练模型的基础上，使用特定数据继续训练，使其更适合某个领域或任务。

# 什么是 Embedding

Embedding（嵌入）是将文本、图片等内容转换为数值向量，以便计算机比较它们的语义相似度。

# 什么是向量数据库

向量数据库用于存储和检索向量，能够快速找出与查询内容在语义上相近的数据。

# 什么是 RAG

RAG（检索增强生成）是先从外部知识库检索相关信息，再让模型结合这些信息生成答案的技术。

# 什么是幻觉

幻觉（Hallucination）是模型生成了看似合理但实际错误、虚构或缺乏依据的内容。

# 什么是多模态

多模态是指模型能够同时理解或生成文本、图片、音频、视频等多种类型的数据。

# 什么是工具调用

工具调用（Tool Calling）是模型按照约定格式请求外部程序执行搜索、计算或文件操作等任务。

# 什么是 Agent

Agent（智能体）可以理解为一个能够围绕目标自主完成任务的 AI 执行者。

Agent 不等于大语言模型。大语言模型主要负责理解和生成内容，Agent 则以大语言模型作为推理核心，再组合规则、上下文、记忆、工具和执行循环：

```text
Agent
= 大语言模型
+ 身份与行为规则
+ 上下文与记忆
+ 工具与权限
+ Agent Loop
```

# 什么是 Agent Loop

Agent Loop（智能体循环）是智能体反复进行观察、思考、行动和检查，直到完成目标或满足停止条件的过程。
